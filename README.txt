ROMANTIC OPEN-WHEN LETTERS WEBSITE
==================================
Open index.html in Chrome/Edge.

This version uses your pasted HTML/CSS/JS as the base and adds:
- A music-choice intro BEFORE the first screen.
- Default Spotify song, surprise option, and visitor's own Spotify link.
- Your supplied Spotify URLs.
- Existing one-screen, no-scroll screen transitions, torn-paper card, flower, sticker and envelope style retained.
- Emoji fallbacks when referenced PNG images are missing.

The supplied flower artwork is included as flower-transparent.png and is used on the page and cards.
Optional sticker and photo artwork can be added beside index.html as:
first.png, second.png, third.png, fourth.png, fifth.png, sixth.png, seventh.png, eighth.png, ninth.png
If those optional images are missing, styled emoji placeholders appear in their place.

Spotify note: links open in a new tab; autoplay is not guaranteed. The surprise selection randomly chooses from the individual songs in SURPRISE_SONGS. Add more individual track URLs there to make the selection genuinely random across more songs. If the list is empty, it opens the playlist.

LIVE EMOJI UPDATE:
- Floating hearts, sparkles, flowers, butterflies and love-letter emojis drift continuously across the viewport.
- Clicking buttons/envelopes creates a small animated emoji burst.
- The animations are decorative and do not block interaction.
